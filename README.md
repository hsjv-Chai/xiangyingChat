# 响应消息（聊天记录阅读器）

一个基于 Electron 的桌面应用，把导出的 HTML 聊天记录以微信式聊天气泡呈现，支持 macOS 与 Windows。界面采用浅色毛玻璃（Glassmorphism）风格：柔和渐变背景、半透明模糊面板、圆角卡片与绿色渐变强调色。

主要特点：

- 🗂 一次导入整个文件夹，左侧微信式会话列表，按最近活跃排序
- 💬 微信风格气泡：头像、昵称、日期分隔、引用卡片；支持文字、图片、图文笔记
- 🔊 AMR 语音播放：内置解码器，支持暂停/继续、时长与进度、播放高亮、本地缓存
- 📤 勾选消息后导出为完整长图（分片截图自动拼接，支持任意多选）
- 🖼 图片灯箱缩放；右键「导出图片 / 复制图片」或灯箱按钮保存为文件
- 🔍 会话内搜索高亮 + 上一处/下一处跳转；侧栏搜索过滤会话
- 📋 文字可选中，右键标准「复制 / 全选」；链接右键「打开 / 复制链接」
- ⚙️ 把某发送者标记为「我」，其消息显示为右侧绿色气泡（微信经典样式）
- 📁 只读浏览：不会修改源文件夹里的任何文件

## 环境要求

- macOS 或 Windows
- [Node.js](https://nodejs.org/) 18+ 与 npm（开发机已安装 Node 24）

## 安装与启动

```bash
# 1. 进入项目目录
cd /Users/hsjv/Documents/ChatGPT/xiangyingChat

# 2. 安装依赖（首次需要联网，会下载 Electron）
npm install

# 3. 启动应用
npm start
```

> 国内网络如果 Electron 二进制下载失败（提示 `fetch failed`），可改用镜像下载：
>
> ```bash
> ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install
> ```
>
> npm 缓存报权限错误（`EACCES`）时，可加 `--cache /tmp/npm-cache-<名称>` 使用临时缓存目录。
>
> macOS 上 `npm start` 会自动把 Dock 应用名设为「响应消息」并应用自定义图标（修改 `node_modules` 里的 Electron.app 并重新签名；重新 `npm install` 后首次启动会自动处理）。

## 首次使用

### 1. 打开聊天记录文件夹

启动后点击「打开文件夹」按钮（左侧会话列表底部，或空状态页中央），选择包含 `.html` 导出文件的文件夹，例如 `响应导出`。

支持的目录结构：

```text
响应导出/
├── 高三15班语文.html          ← 聊天记录文件
├── 高三15班语文/              ← 同名目录：存放该会话的本地图片
│   ├── xxxx.jpeg
│   └── ...
├── 吴亦巨.html
└── 吴亦巨/
```

应用扫描文件夹内全部 `.html` 并自动解析，无法解析的文件会跳过并提示。

### 2. 界面布局

```text
┌────┬──────────────┬──────────────────────────────────┐
│ 图 │  会话搜索框   │  群名称 / 成员数      📤  🔍     │
│ 标 ├──────────────┼──────────────────────────────────┤
│ 栏 │ 会话列表      │  聊天消息区（微信风格气泡）      │
│    │ (按时间排序)  │                                  │
│    ├──────────────┤                                  │
│    │ 打开文件夹    │                                  │
└────┴──────────────┴──────────────────────────────────┘
```

- 最左侧图标栏：顶部应用 Logo，底部齿轮 ⚙ 打开设置；macOS 红绿灯嵌入栏顶
- 中间会话列表：顶部搜索框、会话项（头像、名称、最后一条消息预览、时间）
- 右侧聊天窗口：顶部群名与消息/成员统计，导出与搜索按钮；下方为消息气泡

## 阅读聊天记录

- 消息按时间正序展示，跨天插入居中日期分隔条（今天 / 昨天 / 具体日期）
- 发送者消息靠左（白色气泡），带彩色首字头像和昵称；「我」的消息靠右绿色
- 文字保留换行；`http/https` 链接可点击，用系统默认浏览器打开
- 引用消息在气泡上方显示灰色引用卡片
- 图文笔记：标题加粗，正文与配图一并展示
- 语音消息（AMR）：点击气泡播放，再点暂停/继续，显示时长与进度；播放中高亮，切换或重渲染自动停止

## 图片查看与保存

点击任意图片进入灯箱：

- 滚轮上下滚动 = 缩放；按钮 `−` 缩小 / `+` 放大 / `⤢` 重置 / `✕` 关闭；`Esc` 关闭
- 灯箱右上角 ⬇ 按钮可把图片保存为文件
- 聊天窗口内**右键图片**：`导出图片…`（另存为）或 `复制图片`（剪贴板）

图片优先读取会话同名目录中的本地文件，缺失时回退服务器地址（需联网）。

## 搜索

**会话列表搜索**：顶部搜索框按会话名称、成员、最后一条消息内容过滤。

**会话内搜索**：

1. 点击聊天窗口右上角 🔍 打开搜索栏
2. 输入关键词自动高亮全部匹配，显示 `当前序号/总数`（如 `1/142`）
3. `Enter` 下一处，`Shift + Enter` 上一处；`✕` 或再点 🔍 关闭

## 勾选导出图片

点击聊天窗口右上角 📤 进入「选择导出」模式：

1. 每条消息左侧出现复选框，点消息行或复选框勾选
2. 工具栏显示「已选 N 条」，支持全选 / 清空
3. 点「导出选中」把勾选消息渲染为一张完整 PNG 长图（自动滚动分片截图并拼接）
4. 导出内容包含会话标题、已选数量、日期分隔、文字、图片、引用卡片

`Esc`、点「取消」或切换会话会退出选择模式并清空勾选；超长会话自动降为 1x 清晰度控制体积。

## 设置「我」的发送者

点击图标栏底部齿轮 ⚙，输入发送者姓名（如 `邱明峰`）并保存。该发送者的消息变为微信绿靠右显示；留空则全部靠左。设置自动记忆。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Enter`（聊天搜索框内） | 跳到下一处匹配 |
| `Shift + Enter`（聊天搜索框内） | 跳到上一处匹配 |
| `Esc` | 退出选择模式 / 关闭灯箱 / 关闭设置弹窗 |

## 数据说明

解析导出 HTML 中的 `var array = [...]` 消息数组，兼容的消息类型：

| 类型 | 展示方式 |
| --- | --- |
| `GROUP_TEXT` / `SINGLE_TEXT` | 文字气泡 |
| `GROUP_IMAGE` / `SINGLE_IMAGE` | 图片气泡，点击放大 / 右键保存 |
| `GROUP_NOTE` / `SINGLE_NOTE` | 图文笔记（标题 + 正文 + 图片） |
| `GROUP_AUDIO` / `SINGLE_AUDIO` | 语音气泡，内置 AMR 解码播放 |
| 其他未知类型 | 「不支持的消息类型」占位 |

语音说明：导出文件本身不含音频，首次播放会从消息服务器地址下载并缓存到应用数据目录的 `audio-cache/`，之后可离线复播；若在会话同名目录放有对应的本地 `.amr` 文件，会优先读取本地。

应用只读不改：不会修改「响应导出」目录。设置（上次打开的文件夹、「我」的发送者）保存在用户数据目录的 `config.json` 中：

```text
macOS: ~/Library/Application Support/响应消息/config.json
Windows: %APPDATA%/响应消息/config.json
```

（开发模式 `npm start` 时路径中的「响应消息」为 `wechat-chat-viewer`。）删除该文件即可恢复首次启动状态。

## 常见问题（FAQ）

**启动时窗口一闪而过 / 没反应**
确认通过 `npm start` 启动并从终端查看报错；首次运行需联网下载 Electron，失败时参考上文镜像方案。

**图片不显示**
优先使用本地图片；若会话没有同名图片目录且无法联网，会显示空白占位，联网后重新打开即可加载。

**语音无法播放**
首次播放需联网从服务器下载（导出文件不含音频）；下载失败、文件损坏或解码失败时会提示「语音暂时无法播放」。

**想清空历史记录（上次打开的文件夹 / 「我」的设置）**
退出应用后删除用户数据目录下的 `config.json`（路径见「数据说明」）。

## 已知限制（v1）

- 仅支持「打开文件夹」批量导入，不支持单独拖入单个文件
- 勾选导出为 PNG 单张长图；超长会话自动降为 1x 清晰度，暂不提供分段导出
- 语音仅覆盖 `.amr`（AMR-NB）格式，其他格式由浏览器原生支持或暂不处理
- 未提供安装包签名与自动更新

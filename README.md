# 微信风格聊天记录阅读器

一个基于 Electron 的 macOS 桌面应用，把导出的 HTML 聊天记录以微信式聊天气泡呈现，方便快速浏览、搜索和回看历史消息。界面采用浅色毛玻璃（Glassmorphism）风格：柔和渐变背景、半透明模糊面板、圆角卡片与绿色渐变强调色，整体轻盈现代。

主要特点：

- 🗂 一次导入整个文件夹，左侧微信式会话列表，按最近活跃排序
- 💬 微信风格气泡：头像、昵称、日期分隔、引用卡片；支持文字、图片、图文笔记、语音
- 🔍 会话内搜索：关键词高亮 + 上一处/下一处跳转；侧栏搜索过滤会话
- 🖼 图片点击放大，支持滚轮/按钮缩放
- ⚙️ 把某个发送者标记为「我」，其消息显示为右侧绿色气泡（微信经典样式）
- 📁 只读浏览：不会修改源文件夹里的任何文件

---

## 环境要求

- macOS（已在 macOS 上开发验证）
- [Node.js](https://nodejs.org/) 18+ 与 npm（开发机已安装 Node 24）

## 安装与启动

```bash
# 1. 进入项目目录
cd xiangyingChat

# 2. 安装依赖（首次需要联网，会下载 Electron）
npm install

# 3. 启动应用
npm start
```

> 国内网络如果 Electron 二进制下载失败（提示 `fetch failed`），可改用镜像下载后再安装：
>
> ```bash
> ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install
> ```
>
> 如果 npm 缓存目录报权限错误（`EACCES`），可加 `--cache /tmp/npm-cache-<名称>` 使用临时缓存目录。

## 首次使用

### 1. 打开聊天记录文件夹

启动后点击界面上的「打开文件夹」按钮（位于左侧会话列表底部，或空状态页中央），选择包含 `.html` 导出文件的文件夹，例如 `响应导出`。

支持的结构如下：

```text
响应导出/
├── 高三xx班语文.html          ← 聊天记录文件
├── 高三xx班语文/              ← 同名目录：存放该会话的本地图片
│   ├── xxxx.jpeg
│   └── ...
├── xxx.html
└── xxx/
```

应用会扫描文件夹内的全部 `.html` 文件并自动解析，无法解析的文件会跳过并在界面提示。

### 2. 界面布局

```text
┌────┬──────────────┬──────────────────────────────────┐
│ 图 │  会话搜索框   │  群名称 / 成员数        🔍       │
│ 标 ├──────────────┼──────────────────────────────────┤
│ 栏 │ 会话列表      │  聊天消息区（微信风格气泡）      │
│    │ (按时间排序)  │                                  │
│    ├──────────────┤                                  │
│    │ 打开文件夹    │                                  │
└────┴──────────────┴──────────────────────────────────┘
```

- 最左侧深色竖条为图标栏：顶部是应用 Logo，底部齿轮 ⚙ 打开设置
- 中间为会话列表：顶部搜索框、会话项（头像、名称、最后一条消息预览、时间）
- 右侧为聊天窗口：顶部显示群名与消息/成员统计，下方为消息气泡

### 3. 阅读聊天记录

- 消息按时间正序展示，跨天时自动插入居中日期分隔条（今天 / 昨天 / 具体日期）
- 发送者消息靠左显示（白色气泡），带彩色首字头像和昵称
- 文字消息保留原始换行；消息中的 `http/https` 链接可直接点击，会用系统默认浏览器打开
- 图片消息：小图显示原始比例，点击放大
- 引用消息：气泡上方显示灰色引用卡片（被引用人 + 内容摘要）
- 语音消息：点击语音气泡尝试播放（优先本地文件，缺失时回退服务器地址）
- 图文笔记：标题加粗显示，正文与配图一并展示

### 4. 图片查看

点击任意图片进入灯箱模式：

- 滚轮上下滚动 = 缩放
- 右上角按钮：`−` 缩小 / `+` 放大 / `⤢` 重置 / `✕` 关闭
- 按 `Esc` 关闭灯箱

### 5. 搜索

**会话列表搜索**：点击左侧列表顶部的搜索框，输入关键词即可按会话名称、成员名称、最后一条消息内容过滤会话。

**会话内搜索**：

1. 点击聊天窗口右上角的 🔍 按钮，打开搜索栏
2. 输入关键词，消息区会自动高亮所有匹配位置，并显示 `当前序号/总数`（如 `1/142`）
3. 使用 `↑` / `↓` 按钮或键盘跳转：
   - `Enter`：下一处
   - `Shift + Enter`：上一处
4. 点击 `✕` 或再次点击 🔍 关闭搜索，清除高亮

### 6. 设置「我」的发送者

点击最左侧图标栏底部的齿轮 ⚙：

1. 在「将以下发送者标记为"我"」输入框中填写发送者姓名（例如 `邱明峰`）
2. 点击保存

保存后，该发送者的所有消息会变成微信绿并靠右显示，其余消息保持白色靠左。留空则所有消息都按收到的消息显示。设置会自动记忆，下次启动仍然生效。

### 7. 快捷键汇总

| 按键 | 作用 |
| --- | --- |
| `Enter`（聊天搜索框内） | 跳到下一处匹配 |
| `Shift + Enter`（聊天搜索框内） | 跳到上一处匹配 |
| `Esc` | 关闭灯箱 / 关闭设置弹窗 |

## 数据说明

应用解析导出 HTML 中 `var array = [...]` 的消息数组，兼容以下消息类型：

| 类型 | 展示方式 |
| --- | --- |
| `GROUP_TEXT` / `SINGLE_TEXT` | 文字气泡 |
| `GROUP_IMAGE` / `SINGLE_IMAGE` | 图片气泡，点击放大 |
| `GROUP_NOTE` / `SINGLE_NOTE` | 图文笔记（标题 + 正文 + 图片） |
| `GROUP_AUDIO` / `SINGLE_AUDIO` | 语音气泡，点击播放 |
| 其他未知类型 | 「不支持的消息类型」占位 |

图片加载策略：优先读取「会话同名子目录」中的本地文件（按文件名匹配），本地缺失时回退到导出文件中的服务器地址（此时需要联网）。

应用只读不改：不会修改「响应导出」目录内的任何文件。应用设置（上次打开的文件夹、「我」的发送者）保存在 Electron 用户数据目录的 `config.json` 中：

```text
~/Library/Application Support/wechat-chat-viewer/config.json
```

删除该文件即可恢复首次启动状态。

## 项目结构

```text
xiangyingChat/
├── package.json           # 项目配置与启动脚本
├── src/
│   ├── main.js            # Electron 主进程：窗口、文件扫描、IPC、本地图片协议
│   ├── preload.js         # 安全桥接：向渲染进程暴露受控 API
│   ├── parser.js          # 导出文件解析（纯 Node 模块，可独立测试）
│   └── renderer/          # 前端界面（原生 HTML/CSS/JS，微信风格）
│       ├── index.html
│       ├── styles.css
│       └── app.js
└── test/
    └── parse.test.js      # 解析器测试（node test）
```

## 运行测试

解析器带有针对真实导出文件的自动化测试：

```bash
npm test
```

测试会验证消息数量、类型分布、时间顺序、图片本地命中、会话排序、单聊与语音消息解析等。

## 常见问题（FAQ）

**启动时窗口一闪而过 / 点击后没反应**
先确认是否通过 `npm start` 启动；如从终端启动可看到报错信息。首次运行需要网络下载 Electron，若下载失败请参考上文镜像方案。

**图片不显示**
优先使用本地图片，若会话没有同名图片目录且无法联网，则会显示空白占位。联网后重新打开即可加载服务器地址的图片。

**语音无法播放**
部分导出语音为 `.amr` 等系统不直接支持的格式，此时会提示「语音暂时无法播放」，属正常现象；可回退到服务器地址播放。

**想清空历史记录（上次打开的文件夹 / 「我」的设置）**
退出应用后删除 `~/Library/Application Support/wechat-chat-viewer/config.json` 即可。

## 已知限制（v1）

- 仅支持「打开文件夹」批量导入，不支持单独拖入单个文件
- 仅本地运行（`npm start`），暂不提供 `.dmg` 安装包
- 暂不支持把聊天记录导出为 PDF / 图片
